## 修复内容

- `FINANCE_PROCESS` 表示财务制度咨询，走知识问答；只有 `PROCESS_APPLY` 进入字段提取。用户明确要求提交报销、付款等申请时，应分类为 `PROCESS_APPLY`，与权限申请共用提取服务。字段提取仍不等于提交 n8n。
- 意图 Prompt 明确区分“申请需要谁审批”与“帮我提交申请”，企业内部事实即使可能无答案也需查询知识库。规则兜底同步区分制度咨询和明确办理请求，不再仅凭出现“申请”“远程办公”等词提取字段。
- 回答 Prompt 明确：没查到资料不意味着信息未披露、未发生、尚未确定或不存在；缺少细节时说明知识库没有依据，不能据常识猜测金额、税号、地址或凭据。

本次未改前端、提交接口、n8n 或数据库结构。规则兜底与 Prompt 仍需持续评测，不能保证任意自然语言都能正确分类。
