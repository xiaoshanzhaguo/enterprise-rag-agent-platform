# IT-03 办公设备与数据安全规范

适用范围：使用公司电脑、测试机、移动硬盘、账号和内部系统的全体员工。

## 设备领取

新员工入职当天由 IT 发放办公电脑、充电器和必要外设。员工领取设备时需要确认设备编号、配置、外观状态和资产标签。

员工不得私自拆机、更换硬盘或安装未经授权的远程控制软件。

## 软件安装

办公电脑默认安装浏览器、企业微信、VPN、杀毒软件、文档工具和必要开发工具。需要安装额外软件时，应优先选择公司软件清单中的工具。

涉及抓包、远程控制、数据库客户端和生产访问工具的软件，需要 IT 审核后安装。

## 数据安全

公司内部文档、客户资料、源代码、接口密钥和测试数据不得上传到个人网盘、私人邮箱或公开代码仓库。包含客户信息的数据需要脱敏后才能用于测试和演示。

员工离职或转岗时，需要归还办公设备，并由 IT 检查本地数据、账号登录状态和设备完好情况。

## 密码与账号

企业邮箱、VPN、GitLab 和项目管理系统不得使用相同弱密码。密码至少每 180 天更新一次。发现账号泄露风险时，员工需要立即修改密码并通知 IT。

## 常见问题

Q：可以把公司代码同步到个人 GitHub 吗？  
A：不可以。公司源代码只能保存在公司授权的 GitLab 或代码托管平台。

Q：测试数据能不能给外部供应商？  
A：只有经过脱敏并获得业务负责人审批后，才可以提供给外部供应商。
