# 企业内部知识库样例文档

这个目录用于第 2 天任务：准备可以直接上传到系统里的企业内部知识库样例。

样例按业务部门分为 4 类，每类 3 份文档：

- `hr/`：HR 制度与员工流程
- `finance/`：财务报销、差旅、付款流程
- `it/`：VPN、GitLab、设备安全
- `product/`：产品 FAQ、发布流程、客户反馈处理

## 建议演示方式

1. 启动前端后，在同一个会话里上传某一类或多类 Markdown 文档。
2. 先问一个明确制度问题，观察回答是否带来源引用。
3. 再问一个文档中没有依据的问题，观察系统是否触发无依据拒答。
4. 展开“参考依据”，查看命中的 chunk、score、文件名和原文片段。

## 可直接提问的问题

- 员工请年假需要提前多久申请？
- 试用期员工可以申请几天病假吗？
- 差旅报销需要在多久内提交？
- 单张发票超过多少钱需要额外审批？
- VPN 显示 720 错误应该怎么处理？
- GitLab Maintainer 权限需要谁审批？
- 企业知识助手支持哪些文件格式？
- 产品发布前必须完成哪些检查？

## 样例文档边界

这些文档是演示用的虚拟企业资料，不代表真实公司制度。它们的目标是覆盖 HR、财务、IT、产品 4 类常见内部问答场景，让项目在面试或录屏时看起来更接近真实企业助手。
